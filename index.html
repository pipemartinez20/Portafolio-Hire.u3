La idea

Una red que acompaña el siguiente paso.

HIRE-U reúne en un solo lugar recursos para que la comunidad universitaria encuentre oportunidades y construya su camino profesional.

¿Qué es HIRE-U?

Una propuesta de plataforma laboral universitaria que acerca a estudiantes y egresados a empresas, ofertas de empleo, perfiles profesionales, eventos y una red de contactos.

EmpleabilidadComunidadOportunidades

Una experiencia hecha para avanzar

El proyecto explora flujos de registro e ingreso, recuperación de contraseña y un panel principal; también define la estructura de datos y la planeación necesaria para construir la solución.

07 · Diagrama Modelo Vista Controlador (MVC)

Arquitectura del sistema para conectar egresados, empresas y oportunidades laborales.

Arquitectura MVC · HIRE-UEl modelo MVC (Modelo-Vista-Controlador) organiza Hire-U en tres partes: la Vista, que muestra la interfaz al usuario; el Controlador, que recibe y procesa las solicitudes; y el Modelo, que gestiona los datos y se conecta con MySQL. Estos componentes trabajan juntos para administrar la información de empresas, egresados y ofertas laborales, facilitando la organización, el mantenimiento y la seguridad del sistema..
